# FixOS

A lightweight operating system for the OpenComputers Minecraft mod.

## Features

* Easy installation
* User-friendly graphical interface
* Fast boot process
* Designed specifically for OpenComputers
* Open source

## Requirements

* Internet Card
* Hard Disk Drive

## Installation

Download the installer:

```lua
wget -f https://raw.githubusercontent.com/FixlutGames21/FixOS/main/installer.lua /home/installer.lua
```

Run the installer:

```lua
installer
```

### Installation Steps

1. Download `installer.lua`.
2. Run the installer.
3. Follow the on-screen instructions.
4. Click the blue buttons when prompted.
5. Wait for the installation to complete.
6. Enjoy using FixOS.
